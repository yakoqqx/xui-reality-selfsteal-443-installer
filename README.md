# xui-reality-selfsteal-443-installer

**Установщик VPN-сервера на 3x-ui / Xray: VLESS Reality (self-steal) на 443, VLESS XHTTP, Hysteria2**

[![Русский](https://img.shields.io/badge/%D0%A0%D1%83%D1%81%D1%81%D0%BA%D0%B8%D0%B9-2ea44f?style=for-the-badge)](README.md)
[![English](https://img.shields.io/badge/English-555555?style=for-the-badge)](README.en.md)

</div>

---

Скрипт ставит на VPS панель 3x-ui и настраивает VLESS Reality на 443/tcp. Снаружи сервер выглядит как обычный сайт на вашем домене. По желанию добавляются VLESS XHTTP и Hysteria2. Все протоколы приходят клиенту одной ссылкой подписки. Сертификат Let's Encrypt, nginx, маршрутизацию и ufw скрипт настраивает сам. Можно ставить с нуля или перенести базу `x-ui.db` с другого сервера.

## Требования

- Ubuntu, доступ root или sudo.
- Домен или поддомен, A-запись которого указывает на IP сервера.
- Свободные порты 80/tcp и 443/tcp.
- ufw скрипт настраивает сам. Если используется другой файрвол, в нём нужно открыть 80/tcp, 443/tcp, SSH и UDP-порт Hysteria2.

## Установка

```bash
wget -O install.sh https://raw.githubusercontent.com/yakoqqx/xui-reality-selfsteal-443-installer/main/install.sh
sudo bash install.sh
```

Ответить на вопросы заново:

```bash
sudo bash install.sh --reconfigure
```

Проверить сервер, ничего не меняя:

```bash
sudo bash install.sh --check
```

Удалить то, что поставил скрипт, целиком или по частям:

```bash
sudo bash install.sh --uninstall
```

| Пункт | Что удаляется |
|---|---|
| 1 | 3x-ui: служба x-ui, `/usr/local/x-ui`, `/etc/x-ui`, `/var/log/x-ui`, jail fail2ban `3x-ipl`. Перед удалением база копируется в `/root/x-ui.db.<дата>`. |
| 2 | Конфиги nginx, которые создал скрипт: сайт, антискан, порт 80. |
| 3 | Сертификат `/etc/ssl/<папка>`, домен в acme.sh, `cert-renew.sh` и задача cron. Сам acme.sh удаляется, только если других доменов в нём нет. |
| 4 | Правила ufw, добавленные скриптом. Правило SSH остаётся. |
| 5 | Всё перечисленное, а также сайт-заглушка, файл ответов, журнал и архивы `/root/nginx-*.tgz`. |

Пакеты nginx и fail2ban удаляются по отдельному вопросу. curl, openssl, python3, sqlite3, cron и файлы `/etc/nginx/snippets/xui-panel*.conf` не удаляются.

Чтобы переустановить 3x-ui, удалите пункт 1 и запустите `sudo bash install.sh`.

## Схема

```
80/tcp         → nginx
                   IP, чужой Host → 444
                   домен → /.well-known/acme-challenge/  /var/www/acme
                           остальные пути                301 https://<домен>
443/tcp        → Xray VLESS Reality (SNI = домен, target = 127.0.0.1:7443)
                   клиент Reality → туннель
                   остальные подключения → nginx 127.0.0.1:7443
127.0.0.1:7443 → nginx
                   чужой / пустой SNI, IP → ssl_reject_handshake
                   домен → /                  сайт-заглушка
                           /<путь XHTTP>      Xray XHTTP 127.0.0.1:8081 (опционально)
                           /<путь подписки>   подписка 127.0.0.1:2096
                           /<путь панели>     панель 3x-ui 127.0.0.1:2053
<порт>/udp     → Hysteria2 (опционально)
```

Снаружи открыты только 80/tcp, 443/tcp, SSH и UDP-порт Hysteria2. Во всех ссылках используется домен, а не IP.

## Что настраивается

| Компонент | Настройки |
|---|---|
| Сертификат | Let's Encrypt через acme.sh, ECDSA, проверка HTTP-01 через nginx (webroot `/var/www/acme`). Продлевает `/usr/local/sbin/cert-renew.sh`: cron запускает его каждый день, сертификат обновляется, когда до конца срока меньше 30 дней. |
| nginx | Слушает `127.0.0.1:7443`, TLS 1.3 и h2. Подключения без SNI или с чужим SNI отклоняются (`ssl_reject_handshake`). По секретным путям доступны XHTTP (`grpc_pass`), подписка и панель (`proxy_pass`, WebSocket), остальное — сайт-заглушка. На 80/tcp домен получает редирект на https, остальные запросы — 444. |
| 3x-ui | Панель слушает `127.0.0.1:2053` и открывается только через nginx. Ставится версия, проверенная со скриптом. Если вышла более новая, при установке можно выбрать её. |
| Реклама 3x-ui | Всегда отключена: nginx отдаёт на `/<путь панели>/sponsors` пустой список, на `/<путь панели>/sponsors/` — 404. |
| VLESS Reality | 443/tcp, `xtls-rprx-vision`, fingerprint `firefox`, target `127.0.0.1:7443`, SNI — домен, xver 0. |
| VLESS XHTTP | Опционально. `127.0.0.1:8081`, режим `stream-one`. В подписке: `<домен>:443`, TLS, ALPN `h2`, fingerprint `firefox`. |
| Hysteria2 | Опционально. UDP, сертификат домена, ALPN `h3`, Salamander. Порт по умолчанию 443/udp. |
| Sniffing | На Reality, XHTTP и Hysteria2: `http`, `tls`, `quic`, `routeOnly`. Домен из трафика используется только для маршрутизации, адрес назначения не подменяется. |
| Маршрутизация | → blocked: частные IP (`geoip:private`), IP России (`ext:geoip_RU.dat:ru`), BitTorrent, домены из `ext:geosite_RU.dat:ru-available-only-inside`, зоны `.ru`, `.su`, `.рф`, реклама (`category-ads-all`); UDP/443 для Reality и XHTTP. Свои правила сохраняются, скрипт только дописывает недостающее. |
| Подписка | `127.0.0.1:2096`, ссылка вида `https://<домен>/<путь подписки>/`. |
| ufw | SSH (порт берётся у работающего sshd или ssh.socket), 80/tcp, 443/tcp, UDP-порт Hysteria2. |

Свои директивы для панели, например `sub_filter` для фавиконки, кладутся в `/etc/nginx/snippets/xui-panel*.conf`. Скрипт подключает эти файлы и не меняет их.

Свой сайт-заглушка: при первой установке скрипт делает паузу, чтобы положить в `/var/www/<домен>/` файлы `index.html` и `favicon.ico`, `.svg` или `.png`. Если их нет, ставится страница 403.

## Установка с нуля

Скрипт спрашивает:

1. домен и email для Let's Encrypt;
2. путь к `x-ui.db` — оставить пустым;
3. версию 3x-ui, если вышла новее проверенной;
4. добавлять ли VLESS XHTTP;
5. секретные пути XHTTP, подписки и панели;
6. логин и пароль панели;
7. добавлять ли Hysteria2 и на каком порту;
8. имя первого клиента.

Обязательны только домен и email, остальное при пустом ответе генерируется.

Секретный путь — одна или несколько частей через `/` из букв, цифр, `-` и `_`. Пути не должны совпадать или быть вложены друг в друга.

Порт Hysteria2 по умолчанию 443, `r` выбирает случайный из 20000–60000. Не подходят: 51820, 1194, 500, 4500, 1723; 1–1023, кроме 443; 7443, 8081, 2053, 2096, 62789; порт SSH; занятые UDP-порты.

## Перенос x-ui.db

1. На старом сервере выполнить:
   ```bash
   sqlite3 /etc/x-ui/x-ui.db "PRAGMA wal_checkpoint(TRUNCATE);"
   ```
   и скопировать `/etc/x-ui/x-ui.db` на новый сервер.
2. Перевести A-запись домена на новый IP.
3. Запустить скрипт и указать путь к файлу.

Из базы переносятся клиенты, логин и пароль панели, секретные пути. При переносе:

- Reality переводится на 443, target `127.0.0.1:7443`, SNI — домен; ненулевые `limitFallback*` удаляются. Ключи x25519 и shortIds сохраняются, если Reality уже был настроен так же, иначе выпускаются новые. Если включено несколько Reality-инбаундов, скрипт останавливается и показывает их список.
- Остальные инбаунды на публичных TCP-портах выключаются.
- Если в базе нет XHTTP или Hysteria2, скрипт предлагает их добавить. Для Hysteria2 спрашивает, оставить ли текущий порт.
- Хосты получают адрес-домен и порты 443 (Reality, XHTTP) и порт Hysteria2. Хосты с другим доменом не трогаются.
- `externalProxy` удаляется: ссылки строятся из Хостов.
- Обновляются теги в правилах маршрутизации, `subURI` и правила ufw.
- Можно задать новые логин и пароль панели или оставить прежние.
- 2FA отключается.

Базу из более новой версии 3x-ui, чем установленная, скрипт не переносит: он останавливается до любых изменений и показывает неизвестные миграции и таблицы.

## Проверки

В конце установки и при `--check` проверяется:

- 443/tcp слушает только Xray, nginx — `127.0.0.1:7443` и 80/tcp, Hysteria2 — свой UDP-порт;
- в `config.json` Reality на 443 с target `127.0.0.1:7443`, без ненулевых `limitFallback`, sniffing на инбаундах, правила блокировки и UDP/443 на месте;
- нет соединений на `127.0.0.1:443`;
- `127.0.0.1:7443` отвечает TLS 1.3 и h2 с сертификатом домена и отклоняет подключения без SNI;
- публичный 443 отклоняет подключения без SNI и с чужим SNI, а на домен отдаёт сертификат;
- сайт, панель и подписка открываются через 443, в подписке есть все протоколы;
- запрос рекламы 3x-ui перехватывает nginx;
- на 80/tcp запросы по IP и с чужим Host закрываются без ответа, домен получает 301 на https, `/.well-known/acme-challenge/` доступен;
- acme.sh работает через webroot, `cert-renew.sh` есть в cron root;
- в журнале Xray нет предупреждения о Reality не на 443;
- правила ufw.

Если путь в файле ответов отличается от базы 3x-ui, `--check` покажет предупреждение и проверит по базе.

В конце установки выводятся адрес панели, логин, пароль и ссылка подписки.

## Повторный запуск

Каждый шаг сравнивает текущее состояние с нужным и исправляет только расхождения. На настроенном сервере повторный запуск ничего не меняет, а прерванная установка продолжается с того места, где остановилась.

## Файлы на сервере

| Путь | Назначение |
|---|---|
| `/root/.xui-reality-selfsteal-443-installer.conf` | ответы, логин и пароль панели (0600) |
| `/root/xui-reality-selfsteal-443-installer.log` | журнал (0600) |
| `/etc/nginx/sites-available/<домен>` | сайт |
| `/etc/nginx/conf.d/00-reject-unknown-sni.conf` | антискан 127.0.0.1:7443 |
| `/etc/nginx/conf.d/00-http-reject.conf` | антискан 80/tcp |
| `/etc/nginx/conf.d/10-http-<домен>.conf` | порт 80 домена |
| `/var/www/acme/` | каталог проверок HTTP-01 |
| `/var/www/<домен>/` | сайт-заглушка |
| `/etc/ssl/<домен>/` | сертификат |
| `/usr/local/sbin/cert-renew.sh` | продление сертификата |
