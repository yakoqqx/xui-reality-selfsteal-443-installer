# xui-reality-selfsteal-443-installer

**Скрипт установки 3x-ui и Xray на VPS с VLESS Reality selfsteal (steal_oneself) на 443, XHTTP и Hysteria2**

<kbd><b>Русский</b></kbd> <a href="README.en.md"><kbd>English</kbd></a>

</div>

---

Скрипт ставит на VPS панель 3x-ui и настраивает VLESS Reality на 443/tcp в режиме selfsteal (steal_oneself): Reality маскируется под собственный сайт сервера с его сертификатом, без заимствования чужого домена. Снаружи сервер выглядит как обычный сайт со своим доменом. По желанию добавляются VLESS XHTTP и Hysteria2. Все протоколы приходят клиенту одной ссылкой подписки. Сертификат Let's Encrypt, nginx, маршрутизация и ufw настраиваются в процессе установки. Сервер собирается с нуля или переносится вместе с базой `x-ui.db` с другого сервера.

## Требования

- Ubuntu 24.04, доступ root или sudo.
- Домен или поддомен, A-запись которого указывает на IP сервера.
- Свободные порты 80/tcp и 443/tcp.
- ufw настраивается автоматически. Если используется другой файрвол, в нём нужно открыть 80/tcp, 443/tcp, 443/udp и SSH.

## Установка

```bash
wget -O install.sh https://raw.githubusercontent.com/yakoqqx/xui-reality-selfsteal-443-installer/main/install.sh
sudo bash install.sh
```

При первом запуске выбирается язык (русский или английский) и вариант установки:

- **Стандартная** — только VLESS Reality на 443. Нужны домен и email, остальные параметры заполняются автоматически.
- **Расширенная** — дополнительно XHTTP и Hysteria2, свои пути, логин и пароль панели, перенос базы `x-ui.db`.

Ответить на вопросы заново:

```bash
sudo bash install.sh --reconfigure
```

Проверить сервер, ничего не меняя:

```bash
sudo bash install.sh --check
```

## Схема

```
80/tcp         → nginx
                   IP, чужой Host → 444
                   домен → /.well-known/acme-challenge/  /var/www/acme
                           остальные пути                301 https://<домен>
443/tcp        → Xray VLESS Reality (SNI = домен, target = 127.0.0.1:7443)
                   клиент Reality → туннель
                   остальные подключения → nginx 127.0.0.1:7443
127.0.0.1:7443 → nginx
                   чужой / пустой SNI, IP → ssl_reject_handshake
                   домен → /                  сайт-заглушка
                           /<путь XHTTP>      Xray XHTTP 127.0.0.1:8081 (опционально)
                           /<путь подписки>   подписка 127.0.0.1:2096
                           /<путь панели>     панель 3x-ui 127.0.0.1:2053
443/udp        → Hysteria2 (опционально)
```

Снаружи открыты только 80/tcp, 443/tcp, 443/udp и SSH.

## Что настраивается

| Компонент | Настройки |
|---|---|
| Сертификат | Let's Encrypt через acme.sh, ECDSA, проверка HTTP-01 через nginx (webroot `/var/www/acme`). Продлевает `/usr/local/sbin/cert-renew.sh`: cron запускает его каждый день, сертификат обновляется, когда до конца срока меньше 30 дней. |
| nginx | Слушает `127.0.0.1:7443`, TLS 1.3 и h2. Адрес клиента приходит от Xray по PROXY protocol (`real_ip_header proxy_protocol`). Подключения без SNI или с чужим SNI отклоняются (`ssl_reject_handshake`). По секретным путям доступны XHTTP (`grpc_pass`), подписка и панель (`proxy_pass`, WebSocket), остальное — сайт-заглушка. На 80/tcp домен получает редирект на https, остальные запросы — 444. |
| 3x-ui | Панель слушает `127.0.0.1:2053` и открывается только через nginx. Ставится версия, проверенная со скриптом; более новую можно выбрать при расширенной установке. Файлы проверенной версии сверяются с суммами SHA-256, зашитыми в скрипт. |
| Реклама 3x-ui | Всегда отключена: nginx отдаёт на `/<путь панели>/sponsors` пустой список, на `/<путь панели>/sponsors/` — 404. |
| VLESS Reality | 443/tcp, `xtls-rprx-vision`, fingerprint `firefox`, target `127.0.0.1:7443`, SNI — домен, xver 1. |
| VLESS XHTTP | Опционально. `127.0.0.1`, режим `stream-one`, `trustedXForwardedFor`: `X-Real-IP`. В подписке: `<домен>:443`, TLS, ALPN `h2`, fingerprint `firefox`. Порт по умолчанию 8081. |
| Hysteria2 | Опционально. 443/udp, сертификат домена, ALPN `h3`, без обфускации, masquerade `proxy` на `https://<домен>:443`, `rejectUnknownSni`. Сайт и подписка отдают заголовок `Alt-Svc: h3=":443"` — объявление HTTP/3 на 443/udp. |
| Sniffing | На Reality, XHTTP и Hysteria2: `http`, `tls`, `quic`, `routeOnly`. Домен из трафика используется только для маршрутизации, адрес назначения не подменяется. |
| Маршрутизация | Блокируются частные и российские IP-адреса (`geoip:private`, `ext:geoip_RU.dat:ru`), BitTorrent, домены из `ext:geosite_RU.dat:ru-available-only-inside`, зоны `.ru`, `.su`, `.рф`, реклама (`category-ads-all`) и UDP/443 на Reality и XHTTP. Свои правила сохраняются, недостающие дописываются. |
| Подписка | `127.0.0.1:2096`, ссылка вида `https://<домен>/<путь подписки>/`. Строки называются по Хостам: `VLESS-TCP`, `VLESS-XHTTP`, `HYSTERIA2`. К ответу добавляются заголовки `socks-auth-mode: auto` и `http-auth-mode: auto`: Happ сам задаёт логин и пароль локальных прокси. |
| ufw | SSH (порт берётся у работающего sshd или ssh.socket), 80/tcp, 443/tcp, 443/udp. |

Свои директивы для панели кладутся в `/etc/nginx/snippets/xui-panel*.conf`. Эти файлы подключаются к конфигу и при повторных запусках не меняются.

Свой сайт-заглушка — файлы `index.html` и `favicon.ico`, `.svg` или `.png` в `/var/www/<домен>/`. Если их нет, отдаётся страница 403. Неизвестные пути отвечают 404.

## Удаление

Удалить то, что поставил скрипт, целиком или по частям:

```bash
sudo bash install.sh --uninstall
```

| Пункт | Что удаляется |
|---|---|
| 1 | 3x-ui: служба x-ui, `/usr/local/x-ui`, `/etc/x-ui`, `/var/log/x-ui`, jail fail2ban `3x-ipl`. Перед удалением база копируется в `/root/x-ui.db.<дата>`. |
| 2 | Конфиги nginx, которые создал скрипт: сайт, антискан, real_ip, порт 80. |
| 3 | Сертификат `/etc/ssl/<папка>`, домен в acme.sh, `cert-renew.sh` и задача cron. Сам acme.sh удаляется, только если других доменов в нём нет. |
| 4 | Правила ufw, добавленные скриптом. Правило SSH остаётся. |
| 5 | Всё перечисленное, а также сайт-заглушка, файл ответов, журнал и архивы `/root/nginx-*.tgz`. |

Пакеты nginx и fail2ban удаляются по отдельному вопросу. curl, openssl, python3, sqlite3, cron и файлы `/etc/nginx/snippets/xui-panel*.conf` не удаляются.

## Расширенная установка

Вопросы по порядку:

1. Домен и email для Let's Encrypt.
2. Путь к `x-ui.db` — для переноса базы, при установке с нуля поле остаётся пустым.
3. Версия 3x-ui, если вышла новее проверенной.
4. VLESS XHTTP и его внутренний порт.
5. Hysteria2.
6. Секретные пути XHTTP, подписки и панели.
7. Логин и пароль панели.
8. Имя первого клиента.

Обязательны только домен и email, остальное при пустом ответе генерируется.

Секретный путь — одна или несколько частей через `/` из букв, цифр, `-` и `_`. Пути не должны совпадать или быть вложены друг в друга.

Внутренний порт XHTTP по умолчанию 8081, допустимы 1024–65535.

## Перенос x-ui.db

1. На старом сервере выполнить:
   ```bash
   sqlite3 /etc/x-ui/x-ui.db "PRAGMA wal_checkpoint(TRUNCATE);"
   ```
   и скопировать `/etc/x-ui/x-ui.db` на новый сервер.
2. Перевести A-запись домена на новый IP.
3. Запустить расширенную установку и указать путь к файлу.

Из базы переносятся клиенты, логин и пароль панели, секретные пути. При переносе:

- Reality переводится на 443, target `127.0.0.1:7443`, SNI — домен; ненулевые `limitFallback*` удаляются. Ключи x25519 и shortIds сохраняются, если Reality уже был настроен так же, иначе выпускаются новые. Если включено несколько Reality-инбаундов, скрипт останавливается и показывает их список.
- Остальные инбаунды на публичных TCP-портах выключаются.
- Если в базе нет XHTTP или Hysteria2, скрипт предлагает их добавить. Hysteria2 переводится на 443/udp без обфускации.
- Хосты получают адрес-домен и порт 443. Хосты с другим адресом не трогаются.
- `externalProxy` удаляется: ссылки строятся из Хостов.
- Обновляются теги в правилах маршрутизации, `subURI` и правила ufw.
- Логин и пароль панели остаются прежними или задаются новые.
- 2FA отключается.

Базу из более новой версии 3x-ui, чем установленная, скрипт не переносит: он останавливается до любых изменений и показывает неизвестные миграции и таблицы.

## Проверки

В конце установки и при `--check` проверяется:

- 443/tcp слушает только Xray, nginx — `127.0.0.1:7443` и 80/tcp, Hysteria2 — 443/udp.
- В `config.json` Reality на 443 с target `127.0.0.1:7443` и xver 1, без ненулевых `limitFallback`, Hysteria2 без обфускации, sniffing на инбаундах, правила блокировки и UDP/443 на месте.
- Нет соединений на `127.0.0.1:443`.
- `127.0.0.1:7443` принимает PROXY protocol, отвечает TLS 1.3 и h2 с сертификатом домена и отклоняет подключения без SNI.
- Публичный 443 отклоняет подключения без SNI и с чужим SNI, а на домен отдаёт сертификат.
- Сайт, панель и подписка открываются через 443, в подписке есть все протоколы.
- Запрос рекламы 3x-ui перехватывает nginx.
- На 80/tcp запросы по IP и с чужим Host закрываются без ответа, домен получает 301 на https, `/.well-known/acme-challenge/` доступен.
- acme.sh работает через webroot, `cert-renew.sh` есть в cron root.
- В журнале Xray нет предупреждения о Reality не на 443.
- Правила ufw.

Если путь в файле ответов отличается от базы 3x-ui, `--check` покажет предупреждение и проверит по базе.

В конце установки выводятся адрес панели, логин, пароль и ссылка подписки.

## Повторный запуск

Каждый шаг сравнивает текущее состояние с нужным и исправляет только расхождения. На настроенном сервере повторный запуск ничего не меняет, а прерванная установка продолжается с того места, где остановилась.

## Файлы на сервере

| Путь | Назначение |
|---|---|
| `/root/.xui-reality-selfsteal-443-installer.conf` | ответы, логин и пароль панели (0600) |
| `/root/xui-reality-selfsteal-443-installer.log` | журнал (0600) |
| `/etc/nginx/sites-available/<домен>` | сайт |
| `/etc/nginx/conf.d/00-reject-unknown-sni.conf` | антискан 127.0.0.1:7443 |
| `/etc/nginx/conf.d/30-real-ip.conf` | адрес клиента из PROXY protocol |
| `/etc/nginx/conf.d/00-http-reject.conf` | антискан 80/tcp |
| `/etc/nginx/conf.d/10-http-<домен>.conf` | порт 80 домена |
| `/var/www/acme/` | каталог проверок HTTP-01 |
| `/var/www/<домен>/` | сайт-заглушка |
| `/etc/ssl/<домен>/` | сертификат |
| `/usr/local/sbin/cert-renew.sh` | продление сертификата |
